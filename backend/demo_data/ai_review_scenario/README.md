# 数据库课程教学大纲审核场景

这套材料用于验证“规范配置 -> AI 预审 -> 人工退回 -> 上传整改稿 -> 针对性复审 -> 人工通过”的闭环。材料都是独立生成的样例，不包含真实师生信息。

## 文件

| 文件 | 用途 |
| --- | --- |
| `01_2026级数据科学与大数据技术专业培养方案.docx` | 上位培养依据，规定毕业要求与数据库课程定位 |
| `02_数据科学与大数据技术专业毕业要求指标点_2026版.docx` | 审核课程目标与指标点映射的默认规范 |
| `03_数据库原理及应用课程教学大纲编写规范_2026版.docx` | 审核学时、目标、考核和版本字段的默认规范 |
| `04_数据库原理及应用课程教学大纲_待审核_v1.docx` | 首次提交稿，预设 3 类问题 |
| `05_数据库原理及应用课程教学大纲_整改稿_v2.docx` | 已修正问题，用于退回后上传复审 |
| `06_数据库原理及应用课程考核分析报告.docx` | 上一轮考核归档，辅助说明课程背景 |

首次提交稿中的预设问题：

1. 总学时为 72，各教学单元合计为 64。
2. 考核比例相加为 90%，过程性考核低于规范要求。
3. 团队协作目标 D4 没有对应的项目、汇报或同伴评价。

整改稿把总学时统一为 64，把考核比例调整为 10% + 20% + 20% + 50% = 100%，并为 D4 增加项目汇报、分工记录和同伴评价。

## 生成与验证

重新生成 DOCX：

```powershell
.\.venv\Scripts\python.exe tools\generate_ai_review_scenario.py
```

运行真实 AI 闭环并写入证据报告：

```powershell
.\.venv\Scripts\python.exe tools\run-ai-review-smoke.py
```

脚本使用临时 SQLite 数据库和临时上传目录，结束后自动删除临时数据。真实调用需要 `backend/.env` 配置 `COSMOS_API_KEY`。

Web 手工验证步骤见仓库根目录 `docs/testing-guide.md` 的 5.7 节。
