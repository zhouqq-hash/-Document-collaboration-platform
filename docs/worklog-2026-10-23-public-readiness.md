# 工作日志 2026-10-23：公网可用性与恢复能力

## 目标

把现有演示应用补到可供老师日常公网使用的基础条件：

- 重启后数据库和附件不丢；
- 越权操作继续返回 403；
- AI 不可用时仍能完成审核并继续业务；
- 故障有追踪号、可自检、可备份恢复；
- 生产环境不再使用临时盘、演示弱口令和模拟微信登录。

## 本次改动

| 项 | 内容 |
| --- | --- |
| 生产配置 | 支持 `DATABASE_URL`、`UPLOAD_FOLDER`、`BACKUP_FOLDER`，支持 SQLite / PostgreSQL + psycopg 3 |
| Render | 改为 `starter` + `/var/data` 持久盘，生产不执行 seed，首次创建强密码管理员 |
| 启动保护 | 迁移 → 遗留预审回收 → 管理员初始化 → `doctor --strict` → Gunicorn |
| 就绪检查 | `/api/health` 检查进程，`/api/ready` 检查数据库与文件存储 |
| 错误追踪 | 所有响应带 `X-Request-ID`，5xx 页面显示追踪号，统一 API 404 / 405 / 500 / 409 / 503 |
| 权限 | 保留管理员、文档负责人、表格创建人和普通教师边界；AI 重试与人工兜底同样校验归属 |
| AI 降级 | 失败/跳过记录可重试；负责人填写核验依据后可明确选择人工兜底；原始失败原因保留 |
| 恢复 | `backup` 生成一致性数据库 + 文件 ZIP；`restore` 自动生成恢复前快照；`recover-reviews` 处理中断任务 |
| 静态资源 | 显式返回 `text/javascript`，修复严格浏览器拒绝执行 `app.js` 的上线阻断问题 |
| 安全 | 生产关闭模拟微信登录、启用 Secure Cookie，弱口令/临时盘/默认密钥会阻止启动 |
| 登录页 | 移除硬编码演示账号；只有开发/显式演示环境才由 API 返回并预填 |
| SQLite | 显式启用外键、WAL 和 30 秒 busy timeout，降低多线程写锁失败 |
| 账号开通 | `create-user` 默认隐藏输入密码并二次确认，避免密码进入命令历史 |
| 公网验收 | 新增两阶段验收脚本：写入标记 → 重启服务 → 校验数据 → 教师越权 403 → 清理 |
| 免卡部署 | PythonAnywhere 改为生产持久部署，关闭 seed/模拟登录，自动持久化随机密钥 |
| 免卡引导 | 新增 PythonAnywhere 初始化脚本，自动检查仓库、迁移、创建管理员并运行严格自检 |
| 环境预检 | 引导脚本在写入前检测 Python 版本与 `_posixsubprocess`；新增解释器可用性检查脚本 |
| 国内部署 | 新增腾讯云轻量 Docker Compose、Caddy 自动 HTTPS、持久卷和首次部署脚本 |
