# 工作日志 2026-10-23：登录默认进入工作台

## 问题

登录页没有 `next` 参数时，默认回跳仍写死为文档分类页；微信回调也直接跳到文档分类。未登录访问受保护文档页面时，跳登录页没有带上原页面地址，登录后会丢失上下文。

## 调整

- 无 `next` 时，普通登录、已有会话检查和微信登录统一进入工作台 `/`。
- 从文档、问答、表格等受保护页面跳转登录时，登录页带上原路径，成功后回到原页面。
- 微信回调在独立页面完成时默认进入工作台。
- 登录页文案改为“登录后进入工作台”。
- 工作台“文档管理”卡片和“全部文档”链接改为直接进入 `documents/categories.html`，不再绕经登录页。

## 验证

- 直接打开登录页并登录，最终 URL 为 `/`。
- 未登录访问 `/documents/categories.html`，登录后回到该页面。
- 工作台已有 `next=/`，行为保持不变。
- 已登录时从工作台点击“文档管理”，进入文档分类页而不是回到工作台。
