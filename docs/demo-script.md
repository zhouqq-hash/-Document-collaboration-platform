# 文档管理模块 · 演示脚本

用途：向老师（或评审）演示文档管理模块的功能，目标是在 10 分钟内讲清「做了什么、怎么用、怎么保证质量」。

## 0. 演示前 5 分钟：环境检查

```powershell
# 在仓库根目录执行：把下面的路径换成你自己 clone 或解压出来的目录
cd 'C:\path\to\doc-collab-platform'

# ① 确认 5000 端口没被别的程序占用（如果输出里有 LISTENING，先停掉那个进程）
netstat -ano | findstr :5000

# ② 初始化并启动
.\.venv\Scripts\python.exe -m flask --app backend\run.py db upgrade
# ③ 把数据恢复到初始状态（文档 5 篇、版本都是 v1、上传目录清空）
.\.venv\Scripts\python.exe -m flask --app backend\run.py demo-reset --yes
.\.venv\Scripts\python.exe backend\run.py
```

浏览器打开 `http://127.0.0.1:5000/`，应该看到原型入口页。

演示前确认三件事：

- [ ] 三个账号都能登录：`admin / admin123`、`teacher / teacher123`、`viewer / viewer123`
- [ ] 登录页出现微信入口（没配 `WECHAT_APP_ID` 时是「模拟微信扫码登录」，见 `docs/wechat-login-guide.md`）
- [ ] 准备一个要上传的文件：先跑 `.\tools\make-test-files.ps1`，用生成的 `testdata\sample-ok.txt`（也可以用自己的 Word/PDF 文件，≤ 50 MB）
- [ ] 关闭无关窗口，浏览器只留一个标签页


## 2. 演示流程（约 8 分钟）

| 步骤 | 操作 | 讲解要点 | 应该看到 |
| --- | --- | --- | --- |
| 1 | 停在原型入口页 | 入口页只有文档管理原型这一个入口；本期只做这个模块 | 一张卡片 |
| 2 | 点进「文档管理原型」，用 `admin / admin123` 登录 | 三种权限：管理员、文档负责人、普通教师；登录页同时提供微信扫码入口 | 进入文档分类页 |
| 3 | 看分类列表 | 5 个默认分类，每个分类显示文档数量 | 专业培养计划 2 份、教学大纲 2 份、考核分析报告 1 份，其余 0 份 |
| 4 | 点「专业培养计划」 | 列表支持按分类筛选，状态列能看出文档是否归档、废弃 | 表格：标题 ｜ 分类 ｜ 负责人 ｜ 状态 ｜ 当前版本 ｜ 更新时间 |
| 5 | 点文档标题进详情 | 详情显示当前版本、负责人、更新时间 | 「下载当前版本」「上传新版本」「查看历史版本」三个入口 |
| 6 | 点「查看历史版本」 | 版本按倒序展示，每条都有文件名、变更说明、上传人、上传时间；历史版本只读，不能改也不能删 | 复位后只有 v1；上传过新版本后 v2 在 v1 上面 |
| 7 | 回详情，点「下载当前版本」→ 确认下载 | 这是真实的文件流，不是假链接 | 下载确认页 + 浏览器下载到文件 |
| 8 | 退出，用 `teacher / teacher123` 登录，进详情 → 「上传新版本」→ 选文件 + 填变更说明 → 提交 | **重点**：版本号自动 +1，上传人和上传时间由系统自动记录，不允许伪造 | 复位后从 v1 变成 v2，历史里多一条记录 |
| 9 | 退出，用 `viewer / viewer123` 登录，进同一个文档 | **重点**：权限差异。普通教师只能看和下载，没有上传入口 | 页面提示「你当前为只读权限，不能上传新版本」 |
| 10 | （可选）回到终端跑测试 | 关键规则都有自动化测试兜底 | `239 passed` |
| 11 | （可选）退出登录，在登录页用「模拟微信扫码登录」进系统，再到右上角「账号设置」把微信绑到 `teacher` | **重点**：没配微信应用时走演示模式，扫码后可以绑到已有工号，权限和负责的文档都不变 | 登录页出现微信入口；绑定后账号设置页显示「已绑定微信」，顶部姓名后面多一个「微信」标记 |

回归测试（后端 227 个用例）：

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests -q
```

只跑微信登录的 60 个用例：

```powershell
.\.venv\Scripts\python.exe -m pytest backend\tests\test_wechat.py -q
```

## 3. AI 审核闭环演示（约 3 分钟）

1. 用 `teacher / teacher123` 打开《数据库原理及应用课程教学大纲（待审核）》。
2. 保持两份默认参考规范被勾选，点「开始预审」。模型应指出总学时 72 与单元合计 64 不一致、考核比例合计只有 90%、团队目标 D4 缺少考核证据。
3. 填写退回原因并点「退回修改」。
4. 点「按意见上传新版本」，选择 `backend\demo_data\ai_review_scenario\05_数据库原理及应用课程教学大纲_整改稿_v2.docx`。
5. 再次预审后，结果应逐条显示上次问题“已解决”，整体为“通过”；点人工确认的「通过」，文档状态变为“已通过”。

如需自动复现，运行：

```powershell
.\.venv\Scripts\python.exe tools\run-ai-review-smoke.py
```

该命令使用临时数据库，不改变当前演示数据；它会真实调用模型并生成 `testdata\ai-review-smoke-report.json`。
