# 文档管理模块 · 测试交底

## 0. 这份文档怎么用

你要测的是「教学文档协作平台」的文档管理模块（2026-09-28 基线）。做法很简单：把第 1 ~ 4 节的环境搭好，然后从第 5 节开始按 TC-01 往下走，**每一步都在「结果」列写实际看到的东西**，对不上预期的就按第 8 节的模板提缺陷。

通过标准：标着「必测」的用例全部通过，或者不通过的地方已经写成缺陷并被确认。

预计耗时：环境准备 10 分钟，走完全部用例 40 ~ 60 分钟。

## 1. 环境准备

在仓库根目录执行（Windows / PowerShell）：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r backend\requirements.txt
python -m flask --app backend\run.py db upgrade
python -m flask --app backend\run.py demo-reset --yes
python backend\run.py
```

然后浏览器打开 `http://127.0.0.1:5000/`。

要求与提醒：

- Python 3.11 以上；桌面版 Chrome 或 Edge，窗口宽度至少 1280。
- 不要用手机、平板或窄窗口测，这个原型只做了桌面端样式。
- 不要双击 HTML 文件用 `file://` 打开，页面必须通过 `http://127.0.0.1:5000/` 访问。
- 如果提示「5000 端口被占用」或打开是 404，见根目录 `README.md` 的「常见问题」。
- 如果提示「在此系统上禁止运行脚本」，先执行 `Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned`。
- 终端里中文显示成乱码时，先执行 `$env:PYTHONIOENCODING = "utf-8"` 再跑命令。

## 3. 测试素材

```powershell
.\tools\make-test-files.ps1
```

脚本会在仓库根目录生成 `testdata\`：

| 文件 | 大小 | 用途 |
| --- | --- | --- |
| `sample-ok.txt` | 90 B | 正常上传，应该成功 |
| `sample-bad.png` | 70 B | 不支持的格式，应该被拒绝 |
| `sample-oversize.txt` | 60 MB | 超过 50 MB 上限，应该被拒绝 |

`testdata/` 不进版本库，换台机器重新跑一次脚本即可。

## 4. 每轮测试前先复位

上传版本、新建文档、改文档状态都会改数据。**每跑完一轮，或者换了人接手，先执行复位再开始**：

```powershell
python -m flask --app backend\run.py demo-reset
```

- 它会清空数据库和 `backend/media/` 里的上传文件，然后重新写入演示数据。默认会先问你一句，输入 `y` 继续。
- 自动化或脚本里用 `--yes` 跳过确认。
- 只想重置数据库、保留已上传文件，加 `--keep-media`。

## 6. 预期内的现象（不算缺陷）

- 未登录打开受保护页面时，浏览器网络面板会有一条 `/api/auth/me` 的 401，然后才跳登录页。
- 密码错误登录时，网络面板会有一条 `/api/auth/login` 的 401。
- 不选文件提交时，提示是浏览器自带的原生校验，文案语言跟随浏览器语言。
- 上传超限、格式不对、无权限提交时，页面用的是浏览器弹窗（`alert`），需要点「确定」。
- 已经登录的状态下打开登录页，会被自动跳到分类页。
- 顶部导航在管理员和普通教师下不一样：管理员多出「新建文档」「分类管理」。

## 7. 已知限制（本期不修，按预期记录即可）

| 现象 | 说明 |
| --- | --- |
| 普通教师能打开上传页、看到上传表单 | 上传页前端没做权限拦截，权限由服务端在提交时校验（TC-23 已验证会拒绝）。属于体验问题，不影响安全 |
| 文档列表没有「按状态筛选」的入口 | 需求里只要求按分类筛选；状态筛选接口已存在（`/api/documents?status=`），页面暂未开放 |
| 历史版本不能删除、不能覆盖 | 这是需求明确规定的行为，不是缺陷 |
| 真实微信扫码不可用 | 演示模式交付；真机联调需要企业主体、微信认证和备案域名，本期暂停 |
