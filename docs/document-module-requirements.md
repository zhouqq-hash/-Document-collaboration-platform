# 文档管理模块需求说明

## 1. 范围

本文档只覆盖“教学文档协作平台”的文档管理模块。问答管理、表格协作不在本期范围内。

## 2. 用户角色

| 角色 | 权限 |
| --- | --- |
| 管理员 | 管理文档分类、创建/编辑文档、上传任意文档新版本、查看和下载所有文档 |
| 文档负责人 | 为自己负责的文档上传新版本，查看和下载文档 |
| 普通教师 | 查看和下载全部文档，不能修改或上传版本 |
| 未登录用户 | 只能看到登录页，不能访问业务接口 |

## 3. 功能需求

### 3.1 登录

- 使用工号和密码登录。
- 支持微信扫码登录：没配置微信应用信息时使用演示模式（模拟扫码），配置后走微信开放平台 / 公众号授权。
- 微信可以绑定到已有工号，绑定后扫码登录的是同一个账号，权限和负责的文档不变。
- 未指定回跳地址时，登录成功后进入平台工作台；从受保护页面跳转登录时，登录后返回原页面。
- 未登录访问受保护页面时跳转登录页。

### 3.2 文档分类

- 默认分类：专业培养计划、教学大纲、毕业设计要求、考核分析报告、其他。
- 管理员可新增分类。
- 分类列表展示分类名称和文档数量。

### 3.3 文档列表

- 可按分类筛选文档。
- 列表展示：标题、分类、负责人、最新版本号、最近更新时间。
- 点击文档进入文档详情。

### 3.4 文档详情

- 展示文档标题、分类、负责人、当前版本号和更新时间。
- 提供“下载当前版本”“上传新版本”“查看历史版本”入口。

### 3.4.1 新建文档

- 管理员可从文档列表直接进入“新建文档”，从某个分类筛选进入时自动带入该分类。
- 表单分为“文档信息”和“首个版本”两段；负责人默认当前管理员，可改选其他账号。
- 新建文档必须同时提交首个文件并生成 v1，不产生没有文件的空文档。
- 版本说明默认“初始版本”，收在高级设置中；文档说明可选。
- 标题最多 200 字，说明和版本说明最多 500 字，文件类型和 50 MB 上限在提交前提示。
- 错误在对应字段附近显示，不再依赖浏览器弹窗。

### 3.5 上传新版本

- 首次上传生成 v1，后续每次上传版本号自动递增：v1 -> v2 -> v3。
- 上传时填写变更说明。
- 上传者由系统自动记录，不允许伪造。
- 历史版本只读，不能覆盖或删除。

### 3.6 历史版本

- 按版本号倒序展示历史版本。
- 每条记录包含版本号、文件名、变更说明、上传人、上传时间。
- 历史版本支持查看和下载。

## 4. 业务规则

- 一个文档属于一个分类。
- 一个文档可以有多个版本，版本号在同一文档内唯一且连续递增。
- 最新版本默认展示为当前版本。
- 只有管理员或该文档负责人可以上传新版本。
- 所有已登录教师均可查看和下载。
- 上传文件类型允许：PDF、DOC、DOCX、XLS、XLSX、PPT、PPTX、TXT。
- 单个文件大小上限：50 MB。
- 文档状态：正常（active）、归档（archived）、废弃（deprecated），默认正常，管理员可修改。
- 微信自动创建的账号没有密码，不能用工号密码登录；已绑定且仍有密码的账号可以解绑微信。
- 一个微信只能绑定一个账号，一个账号也只能绑定一个微信。

## 5. 非功能要求

- MVP 使用 SQLite 数据库和本地文件存储。
- 后端提供 JSON API，前端使用静态网页调用 API。
- 所有写操作必须校验权限，读操作必须校验登录状态。
- 关键操作需要自动化测试覆盖。

## 6. 已确认决策（2026-09-22）

- 最终文档分类清单：v1 沿用现有 5 个分类。
- 上传文件类型不变；单个文件大小上限调整为 50 MB。
- 允许管理员修改文档负责人。
- 需要「废弃 / 归档」状态：文档状态为 正常 / 归档 / 废弃，默认正常。
