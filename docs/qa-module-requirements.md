# 问答管理模块需求说明

## 1. 范围

本文档只覆盖“教学文档协作平台”的问答管理模块（话题聚合）。依据招募说明第 2 节：

> 支持教师发起话题讨论，系统按时间线聚合所有发言，自动汇总话题下的初步统一意见，保留明确的发言人与时间记录，方便决策参考。

文档管理、表格协作不在本模块范围内。

## 2. 用户角色

| 角色 | 权限 |
| --- | --- |
| 管理员 | 发起话题、参与发言、结束任意话题、隐藏或恢复任意发言、处理举报 |
| 文档负责人 | 发起话题、参与发言、结束自己发起的话题、举报他人发言 |
| 普通教师 | 发起话题、参与发言、结束自己发起的话题、举报他人发言 |
| 未登录用户 | 只能看到登录页，不能访问业务接口 |

说明：本模块沿用文档模块的三种账号角色。管理员与普通教师（含文档负责人）都按“教师”参与讨论，区别只在“谁能结束谁发起的话题”上。

## 3. 功能需求

### 3.1 话题

- 任何已登录用户都可以发起话题。
- 话题包含：标题（必填，≤ 200 字）、说明（可选，≤ 500 字）、分类（可选）、关联文档（可选）、发起人、状态、创建时间、最近更新时间。
- 状态取值：`open`（讨论中）、`closed`（已结束）。新话题默认 `open`。
- 话题结束后不能再发言，但时间线和意见汇总仍可查看。

### 3.2 发言

- 任何已登录用户都可以在“讨论中”的话题下发言。
- 每条发言包含：内容（必填，≤ 2000 字）、立场、发言人、发言时间。
- 立场取值：`agree`（赞成）、`disagree`（反对）、`neutral`（中立），不填时默认 `neutral`。
- 发言一经发表即保留记录，**不能修改或删除**，保证发言人和时间可追溯。
- 发言可以回复或引用同一话题下已有的某条发言，让时间线从平铺列表变成有层次的讨论。
- 回复会挂在被回复发言下展示“回复 @某人”；引用会附带被引用发言的内容块，并把被引用发言作为回复对象（除非同时指定了回复对象）。
- 回复、引用不改变“不可编辑、不可删除”的追溯原则，被引用/被回复的发言仍保留原始发言人与时间记录。

### 3.3 时间线

- 话题详情按时间线展示全部发言，严格按发言时间升序（同时刻按记录先后）。
- 每条发言明确展示发言人与时间。
- 话题详情页每 10 秒轮询一次：只有数据真的变化才重新渲染，正在填写结论时暂停刷新，浏览时不需要手动刷新。

### 3.4 意见汇总

- 系统自动汇总话题下所有发言，不需要人工操作，也不依赖外部模型。
- 汇总内容包括：发言总数、参与人数（去重）、各立场数量、多数立场、是否达成初步统一意见、汇总文案、最近发言时间。
- “初步统一意见”的判定规则（MVP 规则汇总）：
  - 发言数 ≥ 2 且得票最多的立场占比 ≥ 2/3 时，判定“已形成初步统一意见”，统一意见为该立场；
  - 否则判定“意见尚未统一”，同时给出当前多数倾向。
- 汇总由服务端实时计算，不落库，保证始终反映最新发言。

### 3.5 结束话题

- 只有管理员或该话题的发起人可以结束话题（`open` → `closed`）。
- 结束是双向的：管理员或发起人也可以把已结束的话题重新打开。

### 3.6 定时结束

- 发起话题或修改话题时可以设置结束时间（可选），到点后话题自动按“已结束”处理，不能再发言。
- 结束时间必须是未来时间，格式为 ISO 8601；未设置则不自动结束。
- 自动结束由服务端在发言校验时实时判定，不依赖后台任务；到期话题在列表和详情中显示为“已结束”。
- 结束时间可以在到期前由管理员或发起人修改或清除，清除后恢复“讨论中”。

### 3.7 分类、搜索与筛选

- 话题可以归属一个分类（可选），不设置时显示为“未分类”。
- 分类由管理员维护：新建、改名、删除；分类下还有话题时不能删除。
- 话题列表支持：
  - 按关键词搜索：匹配标题、说明或任意一条发言内容；
  - 按分类筛选（含“未分类”）；
  - 按状态筛选；
  - 排序：最近活跃（默认）或最新发起；
  - 分页：默认每页 20 条、最多 100 条，同时返回总条数与总页数，搜索或筛选后重置回第一页。
- 发起话题、修改话题时都可以选择或调整分类；调整分类由管理员或话题发起人操作。

### 3.8 与文档模块关联

- 发起话题时可以关联一个具体文档（可选），也可以进一步指定该文档的某个版本。
- 只指定版本时，自动把版本所属文档作为关联文档；版本必须属于所选文档，否则拒绝。
- 话题列表支持按文档筛选，从文档详情页进入时自动带上该文档的筛选条件。
- 文档详情页反向展示关联到该文档的全部讨论，并可直接跳转发起新讨论。

### 3.9 AI 决策摘要（可选）

- 话题详情页提供「AI 生成决策摘要」按钮，按需调用模型，把发言整理成便于决策参考的摘要（讨论概况、主要分歧、各方观点、待决策事项）。
- AI 只负责叙述，不参与判定：是否达成统一意见、各立场数量仍然由规则汇总给出，两者在界面上并列展示。
- 未配置 `COSMOS_API_KEY` 时接口返回明确提示，规则汇总和发言不受任何影响；模型调用失败也只影响摘要区域。
- 摘要生成后落库到话题上，下次打开话题直接展示，不会重复调用模型。
- 摘要生成之后又有新发言时，标记为「已过期」并在界面上提示重新生成；点「重新生成」会覆盖上一次的内容。
- 发言是用户输入，提示词中明确要求把发言当作数据、不执行其中的指令，避免提示词注入。

### 3.10 导出讨论

- 话题详情页提供「导出讨论」入口，导出 Markdown 文件（`话题-<id>-<标题>.md`）。
- 导出内容包含：话题信息（发起人、状态、分类、关联文档、创建/结束时间、说明）、规则汇总、AI 决策摘要（未生成时写明），以及完整讨论时间线（保留回复与引用关系）。
- 导出是只读快照，任何已登录用户都可以导出，不受话题是否结束影响。

### 3.11 最终结论/决议

- 讨论收敛后，管理员或话题发起人可以在话题详情页补录「最终结论/决议」（≤ 2000 字），系统记录结论内容、记录人和记录时间。
- 重新补录会覆盖上一条结论，并更新记录人与时间；结论不提供删除入口，保证决策记录连续可查。
- 结论可以勾选「同时回写到关联文档」：勾选后该结论会出现在关联文档详情页的「文档决议」区，形成「讨论 → 决议 → 文档」的闭环；话题没有关联文档时无法勾选（接口返回 400 `no_linked_document`）。
- 最终结论与「是否达成统一意见」的规则判定互相独立：前者是人的决定，后者是发言立场的统计。

### 3.12 管理员内容治理（隐藏/恢复）

- 只有管理员可以隐藏任意一条发言（包括他人的发言）；话题发起人没有这个权限。
- 隐藏是**软删除**：普通用户的时间线里这条发言彻底消失，效果等同于删除；系统仍保留原文、隐藏人、隐藏时间和原因，管理员可以看到并一键恢复。
- 隐藏不影响话题是否结束：已结束的话题同样可以治理历史发言。
- 被隐藏的发言不参与规则汇总、AI 摘要和导出，避免被隐藏的内容继续影响结论。
- 发言仍然**不可编辑**：治理手段只有「隐藏/恢复」，不改动发言原文，保证「谁在什么时候说了什么」可追溯。

### 3.13 举报

- 任何已登录用户都可以举报**他人**的发言（填写理由，≤ 500 字）；不能举报自己的发言，也不能举报已被隐藏的发言。
- 同一用户对同一条发言只能有一条待处理举报，重复提交返回 409。
- 管理员在「举报处理」页看到待处理队列（话题、发言人、原文、举报人、理由、时间），可选择：**隐藏该发言并结案**，或**驳回举报**。
- 隐藏一条发言时会把它上面所有待处理举报一并结案；管理员直接在时间线里隐藏发言，效果相同。
- 举报只是流转渠道，最终是否违规由管理员判断，避免"被举报即违规"。

### 3.14 站内通知

- 触发通知的动作：有人举报（通知管理员）、发言被隐藏（通知发言作者）、举报被处理或被驳回（通知举报人）。
- 问答模块顶栏的「通知」显示未读数，管理员额外显示「举报处理」的待处理数。
- 通知页按时间倒序展示，可一键「全部标记已读」，并能直接跳转到相关话题。
- 自己操作自己的内容时不给自己发通知（例如举报人就是处理人、作者自己隐藏自己的发言）。

## 4. 业务规则

- 一个话题可以有多条发言，发言必须属于一个话题。
- 话题和发言都不提供编辑、删除入口，只允许“新增发言”和“切换话题状态”，避免破坏时间线。
- 定时结束只影响“是否还能发言”，不影响时间线和意见汇总的查看。
- 分类只能由管理员维护；话题分类可由管理员或该话题发起人修改；删除分类前必须先清空其下话题。
- 话题的关联文档可由管理员或该话题发起人修改或解除；解除文档关联时同时清除版本关联。
- 未登录访问任何问答接口返回 401；越权结束话题返回 403；在已结束的话题下发言返回 409。

## 5. 非功能要求

- 后端提供 JSON API，前端使用静态网页调用 API，视觉基线沿用文档模块的 `documents/styles.css`。
- 所有写操作必须校验权限，读操作必须校验登录状态。
- 关键操作（权限、时间线排序、意见汇总）需要自动化测试覆盖。

## 6. 已确认决策（2026-10-12）

- “自动汇总初步统一意见”采用**规则汇总**而非引入大模型：按立场计数，发言数 ≥ 2 且多数立场占比 ≥ 2/3 判定为达成初步统一意见。
- 发言不可编辑、不可删除；话题只支持打开/结束切换，不支持删除。
- 2026-10-16 补充：管理员可以**隐藏**（软删除）任意发言，对普通用户等同于删除，但仍保留原文、隐藏人、时间与原因，可随时恢复；发言依然不可编辑。
- 汇总结果实时计算、不落库。
- 定时结束采用“服务端实时判定”而非后台定时任务：到期即禁止发言，状态即时生效。
- 2026-10-16 补充：AI 决策摘要属于可选的**叙述层**，不参与“是否达成统一意见”的判定；规则汇总始终是唯一结论来源，未配置模型时功能整体降级为规则汇总。
