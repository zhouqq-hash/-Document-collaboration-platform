## 3. 真机联调遇到了什么（按时间顺序）

1. **把授权地址贴进电脑浏览器** → 微信提示「请在微信客户端打开链接」。公众号网页授权只能在微信内置浏览器完成，这一步是我引导错了。
2. **scope 与 AppID 类型不匹配** → 微信提示「Scope 参数错误或没有 Scope 权限」。测试号必须 `WECHAT_AUTHORIZE_MODE=mp`，默认的 `open` 是给开放平台网站应用用的。
3. **回调地址被生成成 `http://`** → 事件日志里只有 `authorize-url`、没有 `callback`。原因是没显式设置 `WECHAT_REDIRECT_URI`，而穿透把 https 拆成明文 http 转给 Flask，`url_for(_external=True)` 就推成 http。
4. **微信 webview 没带回 cookie** → 日志里 `cookies=False`。原来的 state 只存在 session 里，cookie 丢了就必然校验失败。

前三条已在代码侧修好并有测试覆盖；第 4 条改成「签名令牌 + session 双路径」后，用「完全不带 cookie 的回调」实测能登录成功。但**还缺一次端到端的真机成功记录**，因为排查过程比较折腾、也快到演示节点了。
