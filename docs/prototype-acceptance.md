# 文档管理模块原型验收清单

## 说明

原型位于 `prototype/documents/`（入口页是 `prototype/index.html`），已经接入 Flask API。验收时先启动后端，再逐项确认页面流程、接口返回和权限表现。

同级的 `prototype/taskman/` 是另一份独立原型，不属于本模块的验收范围。

## 验收项

| 编号 | 页面/流程 | 验收标准 | 状态 |
| --- | --- | --- | --- |
| P-01 | 登录页 | 工号密码调用真实登录接口，成功后进入分类列表 | 待验收 |
| P-02 | 分类列表 | 展示默认分类和文档数量，可点击进入文档列表 | 待验收 |
| P-03 | 文档列表 | 可按分类筛选，显示标题/负责人/版本/时间 | 待验收 |
| P-04 | 文档详情 | 展示当前版本，下载/上传/历史入口清晰 | 待验收 |
| P-05 | 上传新版本 | 可选择文件、填写变更说明，提交后出现新版本 | 待验收 |
| P-06 | 历史版本 | 版本倒序展示，包含上传人和时间 | 待验收 |
| P-07 | 下载确认 | 下载前有确认提示，确认后调用真实下载接口 | 待验收 |
| P-08 | 权限提示 | 非负责人/非管理员看到只读提示，不能上传 | 待验收 |

## 冻结条件

- 上述 8 项全部通过。
- 页面文案、字段和流程与 `document-module-requirements.md` 一致。
- 原型中不出现后端接口、数据库等实现细节。
