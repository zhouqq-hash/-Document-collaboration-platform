# prototype/：业务方向原型

这个目录存放业务方向的静态原型，入口是 `prototype/index.html`（通过后端访问就是 `http://127.0.0.1:5000/`）。

| 路径 | 内容 | 是否需要后端 |
| --- | --- | --- |
| `index.html` | 工作台首页：模块入口 + 实时概览（文档数、话题数、最近动态） | 需要，实时数据来自后端 |
| `documents/` | 文档管理模块原型，9 个页面（含微信登录与账号设置） | 需要，先启动 `backend/run.py` |
| `qa/` | 问答管理模块原型，4 个页面（话题列表、话题详情、发起话题、问答分类管理） | 需要，先启动 `backend/run.py` |
| `table/` | 表格协作模块原型，2 个页面（表格列表、表格详情：行内编辑 + 修改记录 + 版本回滚） | 需要，先启动 `backend/run.py` |
| `taskman/` | 任务看板原型（历史文件，已从入口页撤下） | 不需要，数据存在浏览器 localStorage |

## 原型现状

- `documents/` 是文档管理模块的原型，已经接入真实 Flask API，浏览器里点一下就会真的请求后端。
- `qa/` 是问答管理模块的原型，同样接入真实 Flask API，覆盖话题发起、时间线聚合和意见汇总。详细说明见 `qa/README.md`。
- `table/` 是表格协作模块的原型，接入真实 Flask API，覆盖表格创建、行内编辑、修改记录和版本回滚。详细说明见 `table/README.md`。
- `taskman/` 做的是“任务优先级排序”，不接后端，也没有写进文档管理模块的需求。**已经撤出原型入口页，文件先保留在目录里**，等需求方确认是否保留为正式功能；确认不需要时再整体删除。

详细说明见 `documents/README.md`；任务看板的说明保留在 `taskman/README.md`。

## 打开方式

工作台首页现在先校验登录：未登录会跳到文档模块的登录页，登录成功后回到首页，再选择进入对应模块。首页的数字和「最近文档 / 最近讨论」来自真实接口，所以文档管理和问答管理原型都必须先启动后端：

三个模块的顶栏都提供「工作台 / 文档管理 / 问答话题 / 表格协作」的互相跳转，任何角色都能在模块之间切换，不会出现进了文档管理就找不到问答或表格入口的情况。

```powershell
.\.venv\Scripts\python.exe backend\run.py
```

然后在浏览器打开 `http://127.0.0.1:5000/`，先登录，再从入口页进入对应模块。

## 视觉规范

原型在 2026-10-22 做过一次整体重设计（墨档 · 朱批：纸面打底、墨蓝结构、朱砂红只用于批改/印章/警示）。新增页面请对齐下面这套取值。文档管理模块的取值集中在 `documents/styles.css` 的 `:root`；入口页与表格协作模块是独立静态页，各自内联一份同样的基线。

| 项目 | 约定 |
| --- | --- |
| 主色 | 墨蓝 `--ink #345b7d`、`--ink-strong #284c6b`、`--ink-deep #1e3a53`，软底 `--ink-soft #edf2f6`、`--ink-tint #d9e3ec`；朱砂 `--cinnabar #b13a2c`（深 `#942f23`）只用于批改/印章/警示 |
| 中性色 | 正文 `#2b323a`、标题 `#1d2833`、次要 `#6c747e`、发丝线 `#e4e1d8`、纸面底 `#f6f5f1`、卡片 `#fffefb` |
| 字体 | 标题宋体系 `--font-display`（Source Han Serif SC / Noto Serif SC / STZhongsong / STSong / SimSun / Songti SC），正文系统黑体 `--font-sans`；正文 15px / 行高 1.7，页标题 27px 宋体 600，卡片标题 18px 宋体 600，表头 13px 黑体 600 |
| 圆角与阴影 | 圆角 4 / 6 / 10 三档；卡片 `0 1px 0 rgba(29,40,51,.03)`，hover `0 10px 24px rgba(29,40,51,.08)`，浮层 `0 12px 32px rgba(29,40,51,.14)` |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48；内容区最大宽 1120px，上下留白 32 / 64px |
| 结构 | 顶栏 `.topbar`（朱砂印章品牌 SVG + `#topbar` 动态区）；页面标题与副标题包在 `<header class="page-head">` 里，标题干净排布、底部一条发丝线，不再用渐变竖条 |
| 图标 | 只用内联 SVG 或 CSS `mask` + data URI（`--icon-*`），不新增图片文件。状态徽标是方角小戳（3px 圆角 + 小方块），不再是圆点胶囊 |
| 动效 | 过渡 140–200ms `ease`，内容淡入 170ms；必须放在 `prefers-reduced-motion: reduce` 的关闭分支之外 |
| 响应式 | 只做桌面端，1280–1920；不新增断点，但要保证 1280 起不出现横向滚动 |

两条硬约束：

- `documents/app.js` 会拼出 `card`、`table`、`btn btn-primary`、`status-badge status-*`、`search-select*` 等 class，并通过 46 个固定 id 找节点。**这些名字是界面契约，只覆盖样式，不要改名**；改结构前先核对 `app.js`。
- `<td>` 上不要套用 `display: flex` 之类的规则（`.actions` 就是踩过的坑），需要横向排列时用 `td.actions` 显式还原成 `table-cell`。
