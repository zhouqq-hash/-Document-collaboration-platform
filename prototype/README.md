# 文档管理模块静态原型

这是一个不连接后端的静态原型，使用假数据演示文档管理完整流程。

打开顺序：

1. `index.html`：登录。
2. `categories.html`：选择文档分类。
3. `documents.html`：查看文档列表。
4. `document-detail.html?id=101`：查看文档详情。
5. `upload-version.html?id=101`：上传新版本。
6. `versions.html?id=101`：查看历史版本。
7. `download.html?id=101&version_id=1003`：下载确认。

原型只用于确认页面和交互，不包含真实后端逻辑。
