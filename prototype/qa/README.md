# prototype/qa/：问答管理模块原型

问答管理模块的前端原型，已接入真实 Flask API，先启动后端再通过入口页进入：

```powershell
.\.venv\Scripts\python.exe backend\run.py
```

然后打开 `http://127.0.0.1:5000/`，从入口页进入问答管理；或直接访问 `http://127.0.0.1:5000/qa/index.html`。

## 页面

| 页面 | 文件 | 主要使用者 | 关键内容 |
| --- | --- | --- | --- |
| 话题列表 | `index.html` | 所有已登录用户 | 话题、发起人、状态、发言数、参与人数、最近发言 |
| 话题详情 | `topic.html` | 所有已登录用户 | 话题信息、意见汇总、讨论时间线、发言表单 |
| 发起话题 | `new-topic.html` | 所有已登录用户 | 标题、说明 |

## 角色行为

- 所有已登录用户（管理员、文档负责人、普通教师）都能发起话题和发言。
- 只有管理员或话题发起人能看到“结束话题”按钮。
- 话题结束后发言表单隐藏，时间线和意见汇总仍可查看。
- 发言一经发表不可修改或删除。

## 视觉规范

页面共用 `documents/styles.css` 的视觉基线，问答专用样式放在 `qa.css`（立场徽标、意见汇总条形、时间线）。新增样式请对齐 `prototype/README.md` 的取值。
