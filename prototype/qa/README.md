# prototype/qa/：问答管理模块原型

问答管理模块的前端原型，已接入真实 Flask API，先启动后端再通过入口页进入：

```powershell
.\.venv\Scripts\python.exe backend\run.py
```

然后打开 `http://127.0.0.1:5000/`，从入口页进入问答管理；或直接访问 `http://127.0.0.1:5000/qa/index.html`。

## 页面

| 页面 | 文件 | 主要使用者 | 关键内容 |
| --- | --- | --- | --- |
| 话题列表 | `index.html` | 所有已登录用户 | 话题、分类、关联文档、发起人、状态、发言数、参与人数、最近发言；支持搜索、筛选与分页 |
| 话题详情 | `topic.html` | 所有已登录用户 | 话题信息（含分类、关联文档、最终结论）、意见汇总（规则汇总 + 可选 AI 摘要）、讨论时间线（支持回复/引用、自动刷新）、发言表单 |
| 发起话题 | `new-topic.html` | 所有已登录用户 | 标题、说明、分类、关联文档与版本、结束时间 |
| 问答分类管理 | `qa-categories.html` | 管理员 | 新建、改名、删除问答话题分类 |
| 通知 | `notifications.html` | 所有已登录用户 | 举报处理结果、发言被隐藏提醒，可一键全部标记已读 |
| 举报处理 | `reports.html` | 管理员 | 待处理举报队列：查看理由与原文，隐藏该发言或驳回 |

## 角色行为

- 所有已登录用户（管理员、文档负责人、普通教师）都能发起话题和发言。
- 只有管理员或话题发起人能看到“结束话题”按钮。
- 只有管理员能管理问答分类；管理员或话题发起人可以调整话题分类。
- 管理员或话题发起人可以调整话题关联的文档与版本，也可以解除关联。
- 话题结束后发言表单隐藏，时间线和意见汇总仍可查看。
- 发言一经发表不可修改或删除。
- 每条发言都可以回复或引用同话题下已有发言，回复以缩进层级展示，引用会附带被引用发言的内容块。
- 意见汇总卡片里的「AI 生成决策摘要」按需调用模型，生成结果落库；没配 `COSMOS_API_KEY` 时只提示一句，规则汇总照常展示。生成后又有新发言会提示「建议重新生成」。
- 话题操作区有「导出讨论」，导出 Markdown（话题信息 + 规则汇总 + AI 摘要 + 完整时间线）。
- 话题信息区可以「补录最终结论」：管理员或发起人填写结论，勾选「同时回写到关联文档」后，结论会出现在文档详情页的「文档决议」区。
- 话题列表每页 20 条，底部显示总数和上一页/下一页；搜索与筛选会自动回到第一页。
- 话题详情每 10 秒自动刷新一次（有变化才重渲染，填写结论时暂停），时间线标题右侧会显示上次刷新时间。
- 管理员在每条发言下会多一个「隐藏」按钮（被隐藏的显示「恢复」）：隐藏后普通用户完全看不到该发言，也不计入汇总；管理员仍能看到原文、隐藏人和原因，并一键恢复。
- 普通教师在别人的发言下会看到「举报」按钮，填写理由后提交；顶栏「通知」显示未读数，管理员额外显示「举报处理」的待处理数，处理结果会自动通知举报人和发言作者。

## 与文档模块的联动

- 发起话题时可关联一个文档，也可以进一步指定某个版本；从文档详情页点「发起讨论」进入时会自动带上该文档。
- 话题列表支持按文档筛选（带 `?document_id=` 参数时会显示筛选提示）；文档详情页会反向列出关联到它的全部讨论。

## 视觉规范

页面共用 `documents/styles.css` 的视觉基线，问答专用样式放在 `qa.css`（立场徽标、意见汇总条形、时间线）。新增样式请对齐 `prototype/README.md` 的取值。
