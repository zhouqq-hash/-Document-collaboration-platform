原型入口

当前并列放置两个业务原型。它们解决的问题不同：一个是文档管理模块的正式原型，另一个是任务看板的独立原型。

已接入 Flask API

文档管理原型（documents）

文档分类、文档列表、文档详情、上传新版本、历史版本、下载确认。

  • 7 个页面，登录后才能访问
  • 数据来自真实后端，需要先启动 backend/run.py
  • 演示账号：admin / admin123（管理员）
  • teacher / teacher123（负责人）、viewer / viewer123（普通教师）
 纯静态原型 · 无后端

任务看板原型（taskman）

任务优先级自动排序、手动拖拽排序、权重设置、任务详情与状态推进。

  • 4 个页面，数据存在浏览器 localStorage
  • 不需要后端，可单独演示；首次打开会自动载入示例数据
  • 界面样式来自 Bootstrap CDN，离线时布局会退化
  • 当前是独立原型，尚未纳入文档管理模块的需求范围
访问方式：先运行 .\\.venv\\Scripts\\python.exe backend\\run.py，再打开 http://127.0.0.1:5000/ 回到本入口页。任务看板原型也可以直接双击 prototype/taskman/index.html 打开，不需要后端。
