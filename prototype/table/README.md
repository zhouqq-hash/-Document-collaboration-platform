# 表格协作模块原型

表格协作模块的前端原型，和文档、问答模块一样是静态页面 + Flask JSON API，入口从工作台「表格协作」进入。

## 页面

| 页面 | 路径 | 说明 |
| --- | --- | --- |
| 表格列表 | `table/index.html` | 查看全部表格、按名称/说明搜索、新建表格 |
| 表格详情 | `table/table.html?id=<id>` | 行内编辑、新增行/列、修改记录、版本快照与回滚 |

## 交互规则

- 「新建表格」提供两种方式：从空白创建时逐列添加列名；也可以直接上传 `.xlsx`、`.xls`、`.csv`，一步创建并生成 v1。
- 新建对话框会校验重复列名、空列名和最多 30 列；从文件创建时会自动填写表格名称，并在提交前检查文件类型和 5 MB 上限。
- 点击单元格直接编辑，失焦自动保存；方向键移动、`Enter` 下移、`Tab` 右移、`Esc` 放弃本次修改，当前格有高亮。
- 创建者/管理员可点「导入文件」上传 `.xlsx`、`.xls`、`.csv`，读取第一个工作表并整表覆盖。导入前自动保存当前版本，导入后可回滚。
- 公式单元格显示计算结果，聚焦后显示公式原文；支持四则运算、单元格/区域引用及 `SUM`、`AVERAGE`、`COUNT`、`MIN`、`MAX`、`IF`、`ROUND` 等常用函数。
- 无法在平台内计算、但文件内含有原结果的公式会保留原结果并锁定；单元格显示「锁」标记，悬停可看公式和原因。
- 点左侧行号选中整行，点列头选中整列，`Shift` 连选、`Ctrl`/`Cmd` 多选，`Delete` 直接删除。
- 在行号/列头上右键，菜单里提供「删除此行/列」或「删除选中的 N 行/列」；列头右键还有「重命名此列」。
- 列头右边缘可拖拽调整列宽；行尾和列头不再放常驻删除按钮。
- 删除前会自动保存快照，删除后底部浮出「撤销」提示，点一下马上恢复。
- 所有登录用户都可以行内编辑、新增行/列；表格创建者和管理员可以编辑表格信息、删除行、保存快照、回滚版本和删除表格。
- 每次单元格修改都会写入修改记录（操作人、时间、旧值、新值），新增/删除行列也会留痕。
- 版本是「整表快照」：创建表格时生成 v1，新增列会自动生成新版本，创建者可随时手动保存快照；回滚会恢复该快照的完整行列，并把这次回滚也保存为一个新版本，历史不会被覆盖。

## 本地运行

```powershell
.\.venv\Scripts\python.exe backend\run.py
```

打开 `http://127.0.0.1:5000/`，登录后从工作台进入「表格协作」。
